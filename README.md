# MUSCLE ATLAS (MA) — MARK 3

- 200개 운동 도감 데이터 포함 (`app/src/main/assets/data.json`)
- 운동 부위, 난이도, 맨몸·머신·프리웨이트·기능성·재활/가동성 방식, 목적 태그 필터
- 운동 상세 정보, 동작 개념 그림, 주요/보조 근육 정보, 운동 부위 기반 근육 지도, 관련 운동 추천, 저장
- 루틴 편집: 운동별 세트 수와 세트당 반복 수 입력
- 체중, 운동 종류·부위, 세트 수와 반복 수 기반 소모 칼로리 추정
- 로컬 저장, 루틴 기록, 백업·복원
- 오프라인 Android WebView 앱, MA 런처 아이콘
- 화면에 `Made by yunjeongwoo` 제작자 표기

## GitHub 업로드 및 APK 빌드
1. ZIP을 압축 해제하고 `muscle_quest_android` 폴더 안으로 들어갑니다.
2. 그 폴더 안의 파일과 폴더(`.github` 포함)를 새 GitHub 저장소의 최상위 루트에 업로드합니다. `muscle_quest_android` 폴더 자체를 한 겹 더 넣지 마세요.
3. 커밋 후 Actions에서 `Build MUSCLE ATLAS APK` 실행이 성공했는지 확인합니다.
4. 워크플로가 Android SDK 라이선스를 수락하고 Gradle 8.9를 설치한 뒤 빌드합니다. 결과 artifact `muscle-atlas-apk` 안에 `app-debug.apk`가 생성됩니다.

## 칼로리 추정 주의
운동별 세트 수·반복 수, 운동 종류와 부위, 입력한 체중을 이용한 간단한 참고치입니다. 실제 중량, 정확한 운동 시간, 휴식 시간, 개인별 대사 차이를 완전히 반영하지 않으므로 측정값으로 보지 마세요.
